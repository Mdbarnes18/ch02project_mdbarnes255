Building HTML Lists

embedded style sheet
A collection of CSS rules defined directly inside a <style> element within the <head> section of an HTML document.
external style sheet
A standalone file with a .css extension containing CSS rules that are linked to an HTML document using the <link> element.
inline style
CSS declarations applied directly to a single HTML element using the style attribute.
